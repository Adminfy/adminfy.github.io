# Web Adminfy Technologies

Web estática desarrollada con HTML, CSS y JavaScript.

## Estructura

- `index.html`: página principal de presentación.
- `marketing.html`: proceso de desarrollo de marketing y beneficios.
- `automatizaciones.html`: proceso incremental de automatización empresarial.
- `contacto.html`: información de contacto y formulario con envío por `mailto`.
- `css/styles.css`: estilos globales y responsive.
- `js/main.js`: menú móvil, animaciones y lógica del formulario.

## Uso

Abre `index.html` en el navegador o sube todos los archivos a cualquier hosting estático.
