# Eleva Aromas Web

Proyecto estático en HTML, CSS y JavaScript.

## Páginas
- `index.html`: presentación y recomendador de fragancias.
- `marketing-olfativo.html`: explicación de marketing olfativo y recomendador centrado en imagen de marca.
- `higienizacion.html`: página de higienización ambiental.
- `contacto.html`: página de contacto con datos editables.

## Cómo usar
Abre `index.html` en el navegador o sube la carpeta completa a un hosting estático.

## Datos
Los tipos de negocio y fragancias están en `js/data.js`. Para ampliar el catálogo, añade más objetos en `businesses` y más descripciones en `fragrances`.

## Pendiente antes de publicar
Actualiza teléfono, email y dirección reales en `contacto.html` y conecta el formulario a un backend o servicio de formularios.
